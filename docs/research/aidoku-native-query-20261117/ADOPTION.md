# Adoption decision

The BiliComics native-query prototype was **not adopted** after its matched
startup experiment. This directory preserves original reference sources,
license, and prototype ABI analysis; it does not add a runtime helper to main.

The original provenance README remains unchanged because development archives
and verification receipts bind its bytes. Read the final
[BiliComics experiment report](../../NATIVE_QUERY_STARTUP_20261117.md) for the
qualified primary results, retained failed diagnostic, and adoption decision.
The adapted runtime source remains on the experimental
`codex/startup-native-query` branch, based on implementation commits `74c2593`
and `f574b26`.
